# Changelog

All notable changes to p5.keyed are documented here.

## [1.1.0] - 2026-10-10

- Types for sketch globals: add `"types": ["p5/global", "p5.keyed/global"]` to `jsconfig.json`.
- The ES module no longer sets globals. Use `exposeGlobals()` if you need them.
- Works with every p5.js release from 2.0.0 to 2.3.4.

## [1.0.0] - 2026-10-10

First release: the p5.js version of [Keyed for Processing](https://github.com/domizai/Keyed), for p5.js 2.x.
